Решение в: solution.py

## Поставленная задача
Реализация Gradient Descent для модели линейной регрессии, используя numpy

## Описание решения

Признаки X дополнялись единицей в начале, а веса модели содержали bias в качестве первого элемента.

Т.к. я не использовал PyTorch, мне нужно было самостоятельно реализовать градиент функции потерь. В данном случае:

$$\frac{dL}{dw}=\frac{d}{dw}\left(\frac{1}{N}(y-Xw)^T(y-Xw)\right)=\frac{2}{N}X^T(Xw-y)$$

Далее этот градиент, умноженный на learning_rate, вычитался из весов модели n_iter раз. На каждой итерации веса обновлялись, после чего градиент пересчитывался.

Предсказание рассчитывалось как Xw.
