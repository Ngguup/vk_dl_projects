# Обучение свёрточной нейронной сети на датасете MNIST

Решение в: notebook_solution.ipynb

## Описание решения

В качестве модели использовал небольшую сверточную нейронную сеть:
- Conv2d для выделения признаков из изображения
- ReLU для добавления нелинейности
- MaxPool2d для уменьшения размерности
- Linear слои для классификации
- LogSoftmax для реализации кросс-энтропии вместе с nll_loss

1. Изменил batch_size с 64 до 128, чтобы немного уменьшить время обучения и скорость переобучения.
2. Протестировал модель с разными значениями out_channels и kernel_size.
3. Наилучший результат показала исходная модель. Второй по величине accuracy оказалась модель с параметрами out_channels=20 и kernel_size=5. По графику было видно, что она ведёт себя более стабильно, чем исходная модель.
4. По графику также было видно, что за первые 4 эпохи модель не начала переобучаться.
5. Для выбранной модели уменьшил learning_rate до 0.001 и добавил weight_decay=1e-4, чтобы уменьшить переобучение.
6. Увеличил количество эпох и посмотрел на изменение accuracy. По графику было видно, что accuracy перестаёт расти примерно после 8-й эпохи.
7. В результате получил:

Final Accuracy = 0.9904
